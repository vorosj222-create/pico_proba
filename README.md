
Robot Arm Playing Nine Men's Morris

Software for controlling a 3D-printed robot arm that plays Nine Men's Morris.
The Arduino-based program runs on a BTT SKR Pico board, which controls the arm's motors. Higher-level control, including motion computation and camera-based computer vision, runs on a PC using Python code.
